# Bounded Learning

Apply the agreed coding outcome, depth, and time boundary. Theory-only sessions require the user's choice.

- Check the needed prerequisite using observed work or one prediction/explanation; a correct coding attempt can suffice.
- Explain the gap with an example, equation, or call signature. Connect intuition to precision; an analogy is not a proof.
- If reading helps, select a short current official or primary-source section and state what it answers. Return to the named file.
- For a detour beyond the agreement, offer a choice and state any working assumption's limits. If proceeding invalidates the task, propose a smaller deliverable.
- Defer tangents. At the boundary, summarize code, demonstrated understanding, and the next step. Stop quizzes after mastery; do not extend the session to finish a syllabus.
